# X 媒体下载

一款 Android 10 及以上使用的个人媒体下载应用：通过系统分享菜单或复制 X 帖子链接，保存帖子中的视频、图片和 GIF。解析、下载和转换在手机本地完成，不需要自建下载服务器。

## 使用

1. 安装 APK，让手机能够访问 X 和其媒体地址。首次需要时，在应用内的 X 页面自行登录。
2. 在 X 的帖子中选择“分享”→“分享…”→“X 媒体下载”，或复制帖子链接后返回应用；也可在首页手动粘贴链接。
3. 一项媒体会直接下载；多项媒体可以预览、单选、多选或全选。应用会比较能够确认的信息以选择较高画质，无法确认时会提示。
4. 在“记录”中按图片或视频浏览，查看媒体或打开原帖。GIF 保存为真正的 GIF，GIF 色彩数量受格式限制。
5. 视频播放时可点击画面暂停或继续，视频会自动循环。点击底部相机按钮，可以将当前画面保存为 PNG 图片，并在图片记录中查看。

图片和 GIF 保存在 `Pictures/X媒体下载`，视频保存在 `Movies/X媒体下载`。新下载的文件以前缀 `@作者账号_` 命名；无法确认作者时使用 `未知用户`。公共相册中的文件在卸载应用后保留，应用内记录和登录会话则会随卸载移除。

## 编译与验证
